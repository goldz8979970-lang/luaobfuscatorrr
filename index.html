📋 Project Overview

This is a production-ready Roblox Luau obfuscator based on a custom virtual machine architecture. Instead of manipulating Luau source code directly, we compile it to proprietary bytecode that only our VM can execute.

Why VM-Based Obfuscation?

  • ✅ Original source code completely hidden
  • ✅ Bytecode is incomprehensible without the interpreter
  • ✅ Reverse engineering becomes exponentially harder
  • ✅ Can apply polymorphic transformations
  • ✅ 100% functional - no script corruption
  • ✅ Runtime integrity checks possible
  • ✅ Anti-tampering built into VM itself

Architecture Diagram

Original Luau Code ↓ Lexer (Tokenization) ↓ Parser (AST Generation) ↓ Semantic Analysis ↓ Bytecode Compiler ↓ Obfuscation Passes ↓ Encrypted Bytecode ↓ VM Wrapper (Runtime Loader) ↓ VM Interpreter (Execution) ↓ Original Behavior, Protected Code

⚙️ VM Instruction Set (Complete)

Our VM uses a stack-based architecture with 64 core instructions. Each instruction is 1 byte for the opcode, followed by variable-length operands.

Instruction Format

-- Bytecode instruction structure [1 byte: Opcode] [Operand 1] [Operand 2] ...

Complete Instruction Set (32 Core + 32 Extended)

LOAD_CONST (0x01)
Load constant from constant pool to stack
Stack: ... → [constant]
LOAD_VAR (0x02)
Load variable from environment
Stack: ... → [value]
STORE_VAR (0x03)
Store value to variable
Stack: [value] → ...
LOAD_GLOBAL (0x04)
Load global variable
Stack: ... → [global_value]
STORE_GLOBAL (0x05)
Store to global variable
